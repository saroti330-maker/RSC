# 🎓 বিদ্যালয়ভিত্তিক শিক্ষার্থীর তথ্য ডাটাবেজ (SCSP Nilphamari)
### Sun Child Sponsorship Program (SCSP) - নীলফামারী প্রজেক্ট

এই প্রজেক্টের মাধ্যমে নীলফামারী প্রজেক্টের ১৯টি শিক্ষা প্রতিষ্ঠানের মোট ২২৬ জন শিক্ষার্থীর বিস্তারিত তথ্য, প্রোফাইল, আইকার্ড এবং সারসংক্ষেপ ব্রাউজারে সুন্দরভাবে দেখা, ফিল্টার করা, নতুন তথ্য যোগ (Add), এডিট (Edit) এবং ডিলিট (Delete) করা যায়।

---

## 🚀 Render.com-এ ফ্রিতে ওয়েবসাইট হোস্ট করার সহজ নিয়ম

[Render.com](https://render.com) এ এই ওয়েবসাইটটি **সম্পূর্ণ ফ্রিতে (Free Static Site)** হোস্ট করা যায়। এতে কোনো মাসিক খরচ নেই, আনলিমিটেড ব্যান্ডউইথ পাওয়া যায় এবং ওয়েবসাইট কখনো স্লিপ (Sleep) হয় না।

### ধাপ ১: GitHub-এ কোড পুশ করা (যদি আগেই না করা থাকে)
আপনার রিপোজিটরি: `https://github.com/saroti330-maker/RSC.git`

টার্মিনালে নিচের কমান্ডগুলো দিয়ে সর্বশেষ ফাইলগুলো পুশ করুন:
```bash
git add .
git commit -m "Render deployment ready files"
git push origin main
```

---

### ধাপ ২: Render.com এ অ্যাকাউন্ট তৈরি ও লগইন
১. ব্রাউজারে যান: [https://render.com](https://render.com)
2. **"Sign In"** অথবা **"Get Started"** এ ক্লিক করে আপনার **GitHub** অ্যাকাউন্ট দিয়ে লগইন করুন।

---

### ধাপ ৩: নতুন Static Site তৈরি করা
১. Render ড্যাশবোর্ডে গিয়ে উপরের ডানপাশে থাকা **"New +"** বাটনে ক্লিক করুন।
২. ড্রপডাউন মেনু থেকে **"Static Site"** সিলেক্ট করুন।
৩. আপনার GitHub রিপোজিটরিগুলোর তালিকা থেকে **`RSC`** (বা `saroti330-maker/RSC`) রিপোজিটরির পাশে থাকা **"Connect"** বাটনে ক্লিক করুন।

---

### ধাপ ৪: সেটিংস কনফিগার করা
নিচের মতো সেটিংসগুলো নির্বাচন করুন:

| সেটিংস ফিল্ড | কী লিখবেন / সিলেক্ট করবেন |
| :--- | :--- |
| **Name** | `school-wise-students` (বা আপনার পছন্দের নাম) |
| **Branch** | `main` |
| **Root Directory** | ফাঁকা রাখুন (Leave blank) |
| **Build Command** | ফাঁকা রাখুন (Leave blank) |
| **Publish Directory** | `.` (একটি ডট চিহ্ন দিন) |

*(বি.দ্র. এই রিপোজিটরিতে `render.yaml` ফাইল যুক্ত থাকায় অনেক ক্ষেত্রে Render এই তথ্যগুলো স্বয়ংক্রিয়ভাবেই পূরণ করে নেবে)*

---

### ধাপ ৫: লাইভ ওয়েবসাইটে প্রবেশ করা
১. নিচে থাকা নীল রঙের **"Create Static Site"** বাটনে ক্লিক করুন।
২. ১ থেকে ২ মিনিটের মধ্যে ডিপ্লয় শেষ হয়ে যাবে এবং স্ক্রিনে একটি সবুজ টিকচিহ্ন সহ আপনার সাইটের লাইভ লিংক দেখতে পাবেন:
   👉 **`https://school-wise-students.onrender.com`** (বা আপনার দেওয়া নামে)
৩. এই লিংকটিতে ক্লিক করলেই আপনার ওয়েবসাইট সরাসরি ইন্টারনেটে চালু হয়ে যাবে! এই লিংকটি মোবাইল, ট্যাবলেট বা যেকোনো কম্পিউটার থেকে যেকোনো ব্যক্তি দেখতে পারবেন।

## 🛠️ প্রধান বৈশিষ্ট্যসমূহ

- **৬টি আইকার্ড ফিল্টার:** প্রতিষ্ঠানের সংখ্যা, মোট শিক্ষার্থী, ছাত্র, ছাত্রী, গ্রাম এবং গড় আয়ের আইকার্ডে ক্লিক করে তথ্য দেখা ও হাইড করা।
- **ডিফল্ট টেবিল ভিউ:** শিক্ষার্থীদের তালিকা শুরুতেই সাজানো ও গোছানো টেবিল আকারে দৃশ্যমান।
- **আইকার্ড ভিউ:** ইচ্ছামতো ছবির মতো কার্ড ভিউ এবং টেবিল ভিউয়ের মধ্যে সুইচ করার সুবিধা।
- **সম্পূর্ণ সিআরইউডি (CRUD):** 
  - ➕ নতুন শিক্ষার্থী যোগ
  - ✏️ প্রোফাইল এডিট ও আপডেট
  - 🗑️ প্রোফাইল ডিলিট
  - 💾 ব্রাউজার লোকালস্টোরেজে ডেটা সংরক্ষণ
- **এক্সপোর্ট ও প্রিন্ট:** এক ক্লিকে এক্সেল বা সিএসভি (CSV) ফাইল ডাউনলোড এবং প্রিন্ট-ফ্রেন্ডলি ফরম্যাট।
- **অফলাইন ও অনলাইন সাপোর্ট:** কোনো এক্সটার্নাল সিডিএন বা ইন্টারনেটের বাড়তি লাইব্রেরির ওপর নির্ভরশীল নয়; ১০০% সেলফ-কনটেইন্ড।
